# Поле: инструменты обратной связи и баг-репортов (разведка 30.10.2026)

Зачем: владелец попросил новую версию расширения «с превосходством» — работать быстрее (ввод, захват, пометки, видео,
отправка, клавиши). Прежняя разведка — `COMPETITIVE-LANDSCAPE.md` (июль); здесь — что изменилось и что выбрано.

## Кто что делает

| Инструмент | Чем силён | Где слаб |
|---|---|---|
| **Jam.dev** | один щелчок: видео + консоль + сеть + устройство; «мгновенный повтор» последних секунд; ИИ пишет текст отчёта; с 03.2026 — MCP для агентов (логи, сеть, действия, видео, расшифровка); 01.2026 — голосовой репортёр на iOS | облако, свой сервер невозможен; по отзывам G2 повтор и короткие записи иногда не создаются |
| **Marker.io** | скриншот с пометками + консоль, сеть, окружение; двусторонняя синхронизация с Jira; MCP | облако, от $39–59/мес; привязка к элементу — через отдельный режим «выбрать элемент» |
| **BugHerd** | пины на живом сайте, работает с Figma и PDF; MCP | облако; синхронизация с Jira в основном односторонняя |
| **Userback** | запись сеанса, «ИИ-выводы», опросы, портал идей; есть бесплатный тариф | уходит в продуктовую аналитику, отчёт для агента не главное |
| **Faster Fixes** | открытый код, свой сервер, MCP, точный DOM-элемент, консоль, сеть | клиентский виджет, тонкие пометки |

## Параметр · лучший у них · у нас · как превзойти

| Параметр | Лучший у них | У нас до правки | Сделано / план |
|---|---|---|---|
| Ввод текста на любом сайте | у всех виджетов бывают конфликты с горячими клавишами сайта | сайт съедал пробел (balatonmap) | **0.1.0:** клавиатура окна изолирована от сайта + допечатка отменённого символа |
| Какой элемент имелся в виду | Marker / Faster Fixes: отдельный режим «выбрать элемент» — лишний щелчок | только картинка | **0.2.0:** каждая пометка (рамка, овал, стрелка, надпись, рисунок) сама привязывается к элементу страницы, без лишних щелчков; агент получает «Mark 2 (frame) → button "Купить" · css: …» |
| Видео | Jam: мгновенный повтор | запись вкладки по кнопке + обрезка | на уровне; дальше — мгновенный повтор последних 30 с |
| Контекст для агента | Jam MCP: логи, сеть, действия, видео | консоль, сеть, шаги, кадры видео, вложения | + привязка пометок к элементам |
| Обновление инструмента | магазин расширений — само | распакованная папка, владелец не знал, что вышла правка | **0.2.0:** доска раздаёт свежую сборку (`/api/extension`), окно и меню расширения показывают номер версии и «⬆ Новая версия — скачать» |
| Голос вместо печати | Jam iOS: голос → текст отчёта | нет | план: диктовка (Brave не даёт распознавание речи браузера — нужна своя расшифровка на сервере) |
| Свой сервер и MCP | Faster Fixes | есть | паритет |
